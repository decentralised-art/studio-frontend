From a Studio draft to Sepolia

  1. Connect your wallet and open Studio. Use unique names for your draft connectors, conditions and transformations.
  2. Build the graph and set its runtime inputs. Select Create locally to create its dependencies and root on the simulation server. The created entities appear in your Local tab and remain immutable. Select Simulate to run the mixed Local/Network tree on the server without gas.
  3. Select Publish to Sepolia. Studio prepares each dependency before its parent connector. Select the owner account and Sepolia in your wallet, review each transaction and approve it. The wallet needs Sepolia ETH for gas.
  4. Studio saves transaction hashes and checks receipts. Pending status means wait and retry Publish; it resumes confirmation without sending the same transaction twice. After an ambiguous wallet error, use the transaction hash from wallet activity to recover the attempt.
  5. After publication is mined, select Execute on Sepolia. This reads published contracts without a paid transaction. The result includes block number, block hash, Runner address and particles. Safe-block execution and discovery may lag mining; retry Execute later.
  6. Attach a compatible World to interpret the particle streams as music, notation or visuals. Simulation output is marked as local; chain output retains its provenance.

See the API publication and simulation reference for direct API calls. These steps require the current Sepolia-enabled server and the wallet owner of every new entity.
