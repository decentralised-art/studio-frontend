# Deployed Graph

This folder documents the curated onchain musical concept graph.

Use this folder when you need to know what already exists and should be reused.

```text
terminal-scalars.md
  Terminal scalar dependencies used by current worlds.

onset-materials.md
  Curated onset grid connectors.

duration-materials.md
  Curated constant duration connectors.

pitch-materials.md
  Curated circular pitch grammars.

note-tables.md
  Curated MusicXML-compatible product connectors.

dependency-graph.md
  Current dependency graph of deployed musical concepts.

superseded-artifacts.md
  Onchain artifacts that exist but should not be used as curated vocabulary.
```

If a new connector is deployed and accepted as curated vocabulary, document it here and update `dependency-graph.md`.
