# Pitch And Sonority

This folder documents pitch, scale, sonority, row, collection, and pitch-space concepts.

```text
pitch-and-sonority-space.md
  Broad pitch/sonority taxonomy.

pitch-candidate-catalog.md
  Concrete pitch connector candidates and equivalence notes.

serial-set-and-tuning-systems.md
  Serial rows, pitch-class set theory, EDO/microtonal systems, and spectral
  material requirements.

modal-and-cultural-systems.md
  Maqam/ajnas, raga/melakarta, gamelan pathet, and jazz chord-scale systems,
  with notes on what is connector-ready versus metadata/tuning-blocked.
```
