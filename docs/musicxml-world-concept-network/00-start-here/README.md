# Start Here

Read these files before adding or changing MusicXML World concept-network docs.

```text
system-principles.md
  Core source-of-truth for PT/DCN connector semantics, circularity, RI projection,
  material/product connectors, and common taxonomy mistakes.

deployable-connector-recipes.md
  Operational recipes that every P3/P4 concept must reduce to before deployment.

documentation-map.md
  Map of active, historical, exploratory, and adjacent docs.

../corpus-tree.md
  Bird's-eye tree of the whole proposed corpus, including deployed,
  candidate, proposed, and missing areas.

connector-tree-notation.md
  Compact notation for exact connector trees and RI roles.

concept-node-template.md
  Template for documenting reusable musical concepts.
```

The main rule is:

```text
Do not start from conventional music-theory object names.
Start from how PT/DCN connectors actually generate circular materials.
```
