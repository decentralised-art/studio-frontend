# Pitch Material Candidates

Pitch material connectors expose one terminal scalar:

```text
pitch_midi
```

They are not complete MusicXML-compatible note tables until a product connector combines them with:

```text
onset_tick
duration_tick
```

## Families

```text
01-equal-division-generators/
  Repeated add(n) circular generators.

02-ordered-interval-grammars/
  Multi-step cyclic interval grammars such as heptatonic, Messiaen, blues,
  and other scale/material families.

03-named-collections-and-sonorities/
  Important theory objects reduced to exact ordered representatives, chord
  products, or metadata policies.

04-serial-row-materials/
  Exact deployment pattern for twelve-tone and serial row forms.
```
