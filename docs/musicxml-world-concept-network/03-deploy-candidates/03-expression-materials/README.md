# Expression Material Candidates

Expression materials are split between deployable `velocity_midi` streams and
future notation-code scalar maps.

The currently usable terminal scalar is:

```text
velocity_midi
```

Other expressive and notation scalars need world-contract maps before curated deployment.

## Families

```text
01-velocity-materials/
  Candidate velocity_midi materials.

02-notation-codes/
  Future dynamic/articulation/note-kind/notation-control materials that need
  world-contract maps before deployment.
```
